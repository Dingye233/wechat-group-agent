# 前端结构与交互

前端仍然是零构建的原生 HTML/CSS/JS，但页面骨架和交互在 UI v2 里重做过一轮。

## 1. 布局

```text
┌──────────────┬─────────────────────────────────────────────┐
│ 侧边栏 232px │ 顶栏：页面标题 + 搜索/命令（Ctrl+K）         │
│ 品牌          ├─────────────────────────────────────────────┤
│ 会话          │                                             │
│ 助手          │  页面内容（会话 / 助手 / 表情包 / 设置）      │
│ 表情包        │                                             │
│ 设置          │                                             │
│ 连接状态      │                                             │
│ 账号 / 退出   │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

- 主导航从顶部横排移到左侧栏，顶栏只负责「当前页面 + 全局动作」。
- 页面标题、eyebrow 会随路由自动更新。
- 宽度 `≤1180px` 时群聊右栏改为抽屉；`≤900px` 侧边栏收成图标栏；表单变单列。

## 2. 路由

支持 hash 深链，刷新/分享不会丢页面：

```text
#/chats
#/assistant
#/assistant/opencode
#/assistant/dsh
#/stickers
#/settings
```

`showTab()` 负责切换页面并写入 history；浏览器前进/后退通过 `popstate` 恢复。助手右侧面板切换时用 `replaceState` 更新第二段路径，不额外制造历史记录。

## 3. 命令面板

`Ctrl/Cmd + K` 或顶栏「搜索或跳转」打开：

- 跳转四个页面；
- 刷新群列表、上传表情包；
- 直达助手任一面板（工作区 / 终端 / 技能 / 记忆 / 任务 / 联系人 / B站 / 能力 / OpenCode / DeepSeek Harness）；
- 搜索并打开任意群聊。

支持 `↑` / `↓` 选择、`Enter` 执行、`Esc` 或点击遮罩关闭。

## 4. 会话页

- 没有选中群聊时，右栏「群聊控制台」隐藏，中间显示空状态，不再出现一份不可用的表单。
- 选中群聊后右栏出现，分为 **设置 / 任务 / 动态** 三个页签，避免把配置、任务和日志堆在一条长滚动里。
- 群列表状态用两个小圆点表示「读取 / 回复」，不再用文字徽章占位。
- 消息区限制最大宽度，气泡按本人 / Agent / 普通成员区分。

## 5. 助手页

- 左侧对话，右侧功能面板。
- 10 个功能面板从横向小标签改为**纵向二级导航**：工作区、终端、技能、记忆、任务、联系人、B站、能力、OpenCode、DeepSeek Harness。
- 右侧面板独立滚动，对话区高度固定，不再整页滚动。

## 6. 设置页

- 顶部新增「模型接入 / 运行行为 / 记忆 / 提示词 / 数据与边界」分区导航，滚动时高亮当前分区。
- 「保存全部设置」从「运行行为」卡片里移到独立保存条，并在滚动时保持可见；它本来就会保存全部字段，现在语义一致。
- 设置卡片改为单列，表单内部两列，减少左右卡片高度不一致造成的锯齿。

## 7. 样式分层

| 文件 | 作用 |
| --- | --- |
| `frontend/styles.css` | 原有组件样式与登录页 |
| `frontend/ui.css` | UI v2 设计层：tokens、壳层、侧边栏、页面、聊天、助手、设置、响应式 |

调整主题只需改 `ui.css` 顶部的 CSS 变量：

```css
:root {
  --bg: #09090b;
  --panel: #0f1013;
  --line: rgba(255, 255, 255, 0.07);
  --green: #34d399;
  --radius: 12px;
}
```

设计参考：[shadcn/ui](https://github.com/shadcn-ui/ui) 的 tokens / 边框 / focus ring，[Linear](https://linear.app) 的侧边栏与紧凑信息密度，[Geist](https://vercel.com/geist) 的字体与克制的强调色。

## 8. 自测

- 浏览器控制台无异常；
- `Ctrl+K`、深链、前进/后退；
- 无群聊时右栏隐藏；
- 设置分区跳转与保存按钮；
- 宽度 1500 / 1100 / 820 三档截图检查。
