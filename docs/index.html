🧠

mem0 + Chroma 语义记忆：人名、项目、口味、约定，跨会话都记得住。

🖥️

会动手

读写文件、跑命令、装 DSH 插件、写技能、挂定时任务，全部走可控工具层，不碰微信窗口。

📺

B站一条龙

搜视频、看视频、点赞、收藏、评论（能带 [doge] 小黄脸，也能附表情包图片）、发动态。

三分钟跑起来

装依赖 
git clone https://github.com/Dingye233/wechat-group-agent.git
cd wechat-group-agent
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
配模型

控制台填自己的 Base URL / Key / 模型即可，仓库里没有任何内置 Key。

起服务 
./start.bat        # Windows
# 或
uvicorn app.main:app --host 127.0.0.1 --port 8000
开工

打开 http://127.0.0.1:8000：选群、开开关、填人设，剩下的交给它。

个人微信自动化有风控和封号风险，请用小号测试并控制频率；服务默认只监听 127.0.0.1，没有内置鉴权，别直接暴露公网。
