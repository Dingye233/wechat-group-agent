BEHAVIOR

运行行为

推荐使用「微信 PC 4.x（wechatauto-replica）」+ 微信 4.1.12 以上（本机已验证 4.1.15.13）。消息从本地数据库读取，微信在后台或最小化也能实时收消息；发送时短暂唤起微信。按 Alt+P（可改）立即暂停自动操作；暂停后必须回网页点击「重新接管」才会继续，并会校验、重发未成功送达的消息。旧版界面自动化需要微信 3.9.x，WeChatFerry 仅匹配 3.9.12.51。

回复节奏：基础延迟 + 随机追加延迟；连续触发会合并为最新一条；跨群发送有最小间隔；每次回复后额外随机冷却；接近每小时上限时会随机降频。

OPERATOR MEMORY

Agent 记忆

Mem0 状态读取中…

Mem0 OSS（GitHub 约 6 万 star）负责语义记忆提取、检索和衰减；未安装或调用失败时自动回退到本地 SQLite 记忆。遗忘清理只删除超过指定天数的旧记忆，不会删除当前会话上下文。

记忆按 1–5 星重要度筛选并自动去重；建议每次总结保留 4–5 条、上下文注入 8 条左右。
