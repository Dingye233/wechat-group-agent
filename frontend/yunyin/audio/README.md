# 音频采样来源

本目录下的乐器采样转制自开源音源 **FluidR3_GM**(作者 Frank Wen,MIT License),
mp3 版本取自 [gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts)。

| 目录 | 原始乐器 | 游戏中用途 |
| --- | --- | --- |
| zheng | Koto(筝) | 古筝主旋律 / 刮奏 |
| pipa | Shamisen(三味线) | 琵琶对答 / 轮指 |
| wood | Woodblock(木鱼) | 按钮点击音 |
| drum | Taiko Drum(太鼓) | 大鼓 / 副歌鼓点 |
| bell | Tubular Bells(管钟) | 编钟(稀有 / 突破) |
| chime | Glockenspiel(钟琴) | 编磬提示音 |
